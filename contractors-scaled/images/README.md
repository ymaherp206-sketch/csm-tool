# Images

Drop the four project photos in this folder with these names:

| File            | Used for                          |
|-----------------|-----------------------------------|
| `kitchen.jpg`   | Hero image and the Kitchens panel |
| `bathroom.jpg`  | Bathrooms panel                   |
| `basement.jpg`  | Basements panel                   |
| `pool.jpg`      | Pools panel                       |

`.jpeg`, `.png`, and `.webp` also work: the page tries those extensions
automatically if the `.jpg` is missing. Portrait or 4:5 crops look best in
the hero and the desktop gallery; anything landscape is cropped with
`object-fit: cover`.

Aim for roughly 1600px on the long edge and under 400 KB each.
